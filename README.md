# Cat Go! — Privacy Policy

Static site serving the privacy policy for **Cat Go!**
(`com.xoproductions.catgo`), published by XO Labs.

Deployed on Vercel as plain static files — no build step, no dependencies.
`cleanUrls` in `vercel.json` serves `privacy-policy.html` at `/privacy-policy`,
which is the URL registered in the Google Play Console listing.

| File | Purpose |
|---|---|
| `index.html` | Landing page, links to the policy |
| `privacy-policy.html` | The policy itself — **this URL is referenced by the Play listing** |
| `icon.png` | App icon, generated by `tools/make_store_art.py` in the game repo |
| `vercel.json` | Clean URLs + basic security headers |

## Keep it accurate

The policy has to match the **Data safety** declaration in the Play Console. If the
app's data handling changes, update both together:

- adding an ad network (AppLovin MAX is planned) → name it in the Advertising section
- adding analytics → add a section, and declare it in Data safety
- changing purchase handling away from RevenueCat → update the partner table

A policy that contradicts the Data safety form is a common cause of Play rejection,
so treat this file as part of the release checklist rather than write-once.
